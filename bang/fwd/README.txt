카드 이미지 파일 위치 안내
===========================

이 폴더(bang/fwd/)에 이미지를 넣으면 게임 내 카드가 그림으로 자동 교체됩니다.
이미지가 없는 카드는 프로그램이 자동 생성한 그래픽으로 표시됩니다.

권장 이미지 크기: 카드 비율(5:7)에 맞는 것이면 어느 크기든 자동 스케일됩니다.
지원 형식: WEBP, PNG, JPG, JPEG (이 순서로 먼저 찾음)

하위 폴더(game/roles/characters)로 나눠도 되고, fwd/ 바로 아래에
파일명만 두어도 자동으로 인식됩니다.
