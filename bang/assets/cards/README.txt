카드 이미지 파일 위치 안내
===========================

이 폴더에 이미지를 넣으면 게임 내 카드가 그림으로 자동 교체됩니다.
이미지가 없는 카드는 프로그램이 자동 생성한 그래픽으로 표시됩니다.

권장 이미지 크기: 카드 비율(5:7)에 맞는 것이면 어느 크기든 자동 스케일됩니다.
지원 형식: PNG, JPG
